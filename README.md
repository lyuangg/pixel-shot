# Precise Screenshot

Chrome 扩展：将浏览器窗口调整到指定尺寸（精确到视口像素），并截图。截图后自动在新标签页打开预览，支持复制到剪贴板或下载。

## 功能特性

- **4 个预置尺寸**：1280×800、640×400、440×280、1400×560
- **自定义尺寸**：可自由输入任意宽高，可保存并起名，长期保留
- **视口偏移补偿**：自动计算浏览器 UI 边框尺寸，确保截图像素精确等于目标尺寸
- **预览编辑**：截图后新标签页预览，显示图片尺寸和文件大小，支持复制 / 下载
- **尺寸限制**：50px ~ 8000px，防止误输入

## 安装

1. 打开 `chrome://extensions`
2. 开启右上角「开发者模式」
3. 点击「加载已解压的扩展程序」
4. 选择本项目目录

## 使用说明

### 选择尺寸

- 点击扩展图标打开弹窗
- 从下拉框选择预置尺寸或已保存的尺寸
- 选择「自定义…」可输入任意宽高，点击「保存尺寸」并起名后会长期保留；不保存则只在当前生效

### 调整窗口尺寸

点击「调整窗口尺寸」按钮，浏览器窗口会变为所选尺寸（开启「视口偏移补偿」时，网页视口精确等于所选尺寸）。

### 截图

点击「截图」按钮，等待片刻后自动打开新标签页预览：

- 底部显示图片尺寸（如 `1280 × 800 px`）和文件大小
- 「复制」：复制到剪贴板
- 「下载」：保存为 `screenshot-<尺寸>-<时间戳>.png`

## 目录结构

```
├── manifest.json       # 扩展清单（MV3）
├── background.js       # 后台逻辑：窗口调整、截图、数据中转
├── popup.html/.css/.js # 弹窗界面：尺寸选择与操作
├── preview.html/.css/.js # 截图预览页
└── icons/              # 扩展图标
```

## 权限说明

- `tabs`：读取当前标签页信息以计算视口偏移
- `activeTab`：捕获当前标签页截图
- `storage`：持久化保存的自定义尺寸、临时截图数据
- `downloads`：下载截图文件
